# News Headline Keyword Analysis

### 📌 프로젝트 개요

이 프로젝트는 여러 언론사의 기사 제목 데이터를 수집 및 통합하여, Komoran 형태소 분석기를 기반으로 핵심 명사 및 복합 명사를 추출하고 시각화하는 프로젝트입니다. 주요 키워드를 파악하여 언론 보도의 경향성을 분석할 수 있도록 데이터 전처리 및 분석을 수행합니다.

### 🛠 사용 기술 및 도구
- **Python**: 전체 구현 언어
- **Pandas**: 기사 데이터 전처리 및 분석
- **NumPy**: 배열 처리 및 수치 연산
- **Matplotlib**, **WordCloud**: 시각화
- **Komoran**: 한국어 형태소 분석 (복합명사 추출)

### 💡 기대 효과 및 활용 방안

- 언론사의 보도 키워드를 정량적으로 분석함으로써 프레이밍 효과, 편향성 탐지, 이슈 집중도 분석 등에 활용할 수 있습니다.
- 공공정책, 선거, 사회 이슈 등 특정 주제에 대한 언론의 보도 경향을 추적하여, 언론 감시 및 미디어 리터러시 교육 자료로 활용될 수 있습니다.
- 학술 연구, 언론학, 데이터 저널리즘 등 다양한 분야에서 자연어 기반 미디어 분석 도구로 확장 가능합니다.
